# XTRAVAGANZA Recordings (React + Vite)

This build is styled to match the futuristic mock (deep navy + cyan circuit-board HUD background).

## Run locally

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

Repo pages URL format:
`https://<username>.github.io/xtravaganza_recordings/`

If your repo name changes, update `base` in `vite.config.js`.
